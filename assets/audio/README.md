# Reference narration

Status: Device-test assets, generated 2026-11-08

Five WAV files contain the exact corresponding title and story in `transcripts.json`. The text was written for Momentum using the reviewed museum/Staatsbosbeheer facts recorded in `00_Project/Reference_Content_Review.md`. Local Windows System.Speech, installed Dutch voice Microsoft Frank, rate -1, produced this synthetic test narration. No external voice service, voice impersonation or microphone was used.

The UI labels the narration as a computer voice. These are test assets, not a commissioned production voice or a license assessment for public distribution. Final voice quality and public distribution rights remain a release review item.

Changes to story text invalidate the matching audio in `referenceAudio.ts`. Regenerate and review both transcript and audio together. WAVs are bundled for offline playback. Actual duration comes from the audio player, never from a mockup.

Foreground playback only: microphone permission, recording and background playback are disabled. Lock screen/background behavior, interruptions and Dutch pronunciation still require physical iPhone validation. Do not infer that native audio works merely from a successful bundle export.
